# Corrective Appendix — Alternative Website Proposal

## Pop Cultured — Retail Store Concept

> **Note:** The original Part 1 document listed “Pop cultured” as a second organisation name but did not contain a full second proposal. This appendix is a Part 2 corrective addition intended to respond transparently to the lecturer feedback; it is not presented as content that was in the original submission.

### Overview
Pop Cultured is treated here as a specialist retail concept for pop-culture merchandise such as collectibles, apparel and themed accessories. A website would give the store a central branded presence and make product categories, store information and enquiries easier to find.

### Goals and objectives
- Build a recognisable digital identity for the retailer.
- Present product categories clearly without overwhelming users.
- Help customers discover new or featured merchandise.
- Make store location, opening information and enquiries easy to access.
- Provide a structure that could later support e-commerce functionality.

### Proposed pages and functionality
- **Home:** brand introduction, featured categories, current highlights and direct calls-to-action.
- **About:** store story, niche, audience and brand values.
- **Products/Categories:** visual category cards with concise descriptions and room for future product filtering.
- **Enquiry:** form for stock questions, special requests or partnership enquiries.
- **Contact:** store location, communication channels and social media links.

### Design direction
A high-contrast dark interface with bold accent colours would suit the energetic pop-culture theme. Cards and responsive grids would allow featured categories to rearrange cleanly from desktop to mobile.

### Technical direction
Semantic HTML5, one external CSS stylesheet, CSS Grid/Flexbox, responsive images and media queries would provide the same maintainable foundation used in the Meliora Media Part 2 implementation.
